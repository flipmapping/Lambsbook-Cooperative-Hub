# GE-001 Invitation API Contract Capture

## Purpose

Capture the complete runtime contract for the invitation creation request.

No repository mutation is performed.

---

## Steps

### 1. Open Chrome DevTools

Press:

F12

Open the **Network** tab.

Enable:

[x] Preserve log

[x] Disable cache

Clear the existing network log.

---

### 2. Trigger Invitation

Navigate to:

Member Dashboard
→ Invitations

Enter:

cooptesta@spamok.com

Click:

Create Invitation

---

### 3. Locate Request

Select:

POST /api/member/invitations

---

### 4. Capture

Record ALL of the following.

## General

Request URL

Status Code

Remote Address

Request Method

Timing (optional)

---

## Request Headers

Copy all request headers.

---

## Request Payload

Copy the JSON payload exactly.

---

## Response Headers

Copy all response headers.

---

## Response

Copy the raw response body exactly.

---

## Preview

If Chrome shows a Preview tab,
copy it as well.

---

## Console

Copy any console errors produced
immediately after pressing
Create Invitation.

---

## Server Log

If running in Replit,
copy any server console output
generated by the request.

---

## Success Criteria

The following question must become answerable:

Did the backend

A. reject the request,

B. create the invitation,

C. create the invitation but fail to return the invitation URL,

D. fail while generating the invitation link,

or

E. succeed completely while the frontend failed to render it?

No repository mutation is authorized until this runtime contract has been captured.
