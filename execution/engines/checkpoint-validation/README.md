# EOS-034 Checkpoint Validation Engine

Mission

Validate execution checkpoints against the registered checkpoint contract
before certification.

Responsibilities

- Schema validation
- Version compatibility
- Required field validation
- Integrity verification
- Certification readiness

This engine SHALL NOT generate checkpoints.

Checkpoint generation belongs to EMP-002S.

Checkpoint emission belongs to EOS-033.

Checkpoint validation belongs exclusively to EOS-034.
