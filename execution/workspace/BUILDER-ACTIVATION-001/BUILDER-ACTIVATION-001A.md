Augment the Builder request so every generated Production

Builder Exit Criteria
---------------------

The generated PIC shall require implementation teams to record:

- Repository root
- Active branch
- Pre-mutation HEAD SHA
- Post-mutation HEAD SHA
- Commit SHA
- Remote synchronization status
- Deployment artifact identity
- Runtime verification evidence

No implementation package shall be considered complete unless these
requirements are included.
