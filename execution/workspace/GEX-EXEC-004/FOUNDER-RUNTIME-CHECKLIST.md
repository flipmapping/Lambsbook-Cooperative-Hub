# Founder Runtime Checklist

1. Start the app:
   npm run dev

2. Sign in with an existing Admissions-capable account
   (admissions, sbu_admin, or platform_admin).

3. Open Admissions Workspace.

4. Select one existing prospect with an email address.

5. Record:
   - Prospect name
   - Current stage

6. Change the prospect to one new stage.

7. Verify:
   - UI updates successfully
   - No errors
   - One PATCH request succeeds

8. Capture:
   - HTTP request
   - HTTP response
   - Relevant server log
   - Notification record (if available)

9. Populate:
   execution/workspace/GEX-EXEC-004/runtime-evidence/

10. Submit the completed evidence package for review.
