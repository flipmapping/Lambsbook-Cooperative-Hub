
# COM-ARCH-002

Organization Communication Policy

Constitutional Ownership

Organization Communication Profile
                │
                ▼
Organization Communication Policy
                │
                ▼
DispatchDecision
                │
                ▼
Queue
                │
                ▼
ProviderAdapter

Constitutional Rules

1. Organizations own communication policy.

2. DispatchDecision evaluates policy but never defines it.

3. Queue executes authorized work only.

4. Provider adapters perform transport only.

5. Policy changes never mutate historical DispatchDecision records.

Certification

This authority completes the constitutional ownership model by
separating organization policy from runtime authorization.
