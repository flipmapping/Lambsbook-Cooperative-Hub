# Implementation Handoff Guide

This architecture package is frozen.

Repository mutation SHALL consume the package in this order:

1. RELEASE-MANIFEST.json
2. NOTIFICATION-MUTATION-BACKLOG.json
3. MUTATION-EXECUTION-RECORD.template.md
4. NOTIFICATION-IMPLEMENTATION-BLUEPRINT.md
5. NOTIFICATION-PIPELINE-MUTATION-MAP.md

Execution begins with NM-001.

No architectural documents within this package are to be edited.
Any future architectural evolution requires a new implementation
authority or a formal amendment outside this frozen release.
